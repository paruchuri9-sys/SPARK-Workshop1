# SPARK Alpha 1 deployment role policy

This is the scoped deployment policy required by the current SAM template for the GitHub OIDC role `SAIL-GitHub-Deploy`.

It covers the resources generated by the current template: CloudFormation change sets, DynamoDB, generated Lambda execution role, Lambda function and permissions, and the SAM implicit API Gateway V2 HTTP API.

Use this as the SSOT for the temporary Alpha 1 deployment policy. Do not broaden to AdministratorAccess.
